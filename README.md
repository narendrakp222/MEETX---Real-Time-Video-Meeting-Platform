# MEETX - Real-Time Video Meeting Platform

MEETX is a web-based video conferencing platform built with Flask and ZegoCloud.  
Users can create accounts, start meetings, and join meetings using a meeting ID.

---

## Features

- User Authentication (Login / Register)
- Create Meeting Rooms
- Join Meeting via Meeting ID
- Real-Time Video Conferencing
- Chat and Screen Sharing (via ZegoCloud)
- Clean modern UI

---

## Tech Stack

Backend:
- Python
- Flask
- Flask-SQLAlchemy
- SQLite

Frontend:
- HTML
- CSS

Video Communication:
- ZegoCloud Video SDK
